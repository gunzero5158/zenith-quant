# 天台分析 Rooftop Quant

[English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md)

天台分析是一个可自行部署的股票技术分析工作台，覆盖美股、港股、中国 A 股和日本股票市场。它在同一个界面中整合多周期行情、确定性的指标预处理、交互式图表，以及由 AI 独立完成的走势判断和交易建议。

AI 分析仅基于公开行情和常规技术指标，不构成投资建议或买卖指导。市场有风险，请独立判断并自行承担决策后果。

## AI 自主决策流程

这个实验分支不会先计算一个本地规则分，再交给 AI 复核。

1. 本地引擎只负责整理日线和周线数据，计算客观指标数值、事件时间、数据质量和候选交易价位。
2. AI 是走势、0-5 分入场吸引力、置信度、场景状态和持仓/入场/退出建议的唯一判断者。系统没有固定权重、本地评分上限，也没有 `+/-0.5` 的调整限制。
3. 服务端只验证结果，不替 AI 改结论。引用的证据必须真实存在，策略字段必须与所选场景一致，可执行的入场建议必须从已提供价位中选择合理的止损和目标。
4. 盈亏比和止损距离由服务端根据 AI 选择的价位计算，避免输出中的算术矛盾。

置信度表示 AI 对结论的确定程度，不代表看多程度，也不等于分数高低。AI 会综合数据完整性、独立证据是否一致、日周线冲突、未收盘 K 线和触发/失效距离，并给出置信度理由。

## 分析范围

- 趋势与波动：EMA、布林带、一目均衡表、ATR、日线和周线结构。
- 动量：MACD、KDJ、RSI、近期交叉、阈值事件和背离。
- 成交量与资金流：相对成交量、OBV、CMF 和量价确认。
- 价格位置：水平支撑压力、斐波那契、VPVR、动态价位和形态价位。
- 结构与形态：经典图形、带位置语境的 K 线形态、TD Sequential、艾略特波浪启发式分析和缠论背景。
- 决策输出：看多/中性/看空结论、AI 评分和置信度、左右侧状态、四类策略、止损、目标和计算后的盈亏比。

AI 会收到已经计算好的数值和事件时间，但不能重新计算指标，也不能引入新闻、基本面、未提供价位或其他外部事实。模拟 K 线不会被当成真实行情交给 AI 分析。

## 市场与行情

| 市场 | 示例 |
| --- | --- |
| 美股 | `AAPL`、`MSFT` |
| 港股 | `0700.HK`、`9988.HK` |
| 中国 A 股 | `600519.SS`、`000001.SZ` |
| 日本股票 | `7203.T`、`9984.T` |

行情可用性取决于标的、市场、网络和上游服务。应用会按市场在 Yahoo Finance、东方财富、同花顺、Kabutan、腾讯和可选的 Twelve Data/FMP 之间回退。分析历史按对应市场的交易时段判断新鲜度，模拟数据不会被当成实时结果。

## 快速开始

需要 Node.js 20.9 或更高版本，以及 npm。

```bash
git clone https://github.com/gunzero5158/zenith-quant.git
cd zenith-quant
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。分析前请在 **AI 设置** 中配置服务商、模型和 API Key。界面支持 Google Gemini、OpenAI、Anthropic 和 OpenAI 兼容接口。

可在 `.env.local` 中启用额外行情源：

```env
TWELVE_DATA_API_KEY=your_key
FMP_API_KEY=your_key
```

自定义 AI 接口默认不能访问内网地址。自行部署时可通过 `ZENITH_ALLOW_PRIVATE_LLM_HOSTS=true` 显式放开。

## 隐私与限制

- 分析历史、缓存报告、显示偏好和 AI 设置保存在浏览器存储或 Cookie 中。
- AI 凭据会经本应用服务端接口转发至所选服务商，服务端不会主动持久化保存。
- 行情和 AI 输出可能延迟、不完整、不可用或错误。
- 技术指标、形态、评分和生成报告只是决策辅助，不是价格预测或交易指令。
