# 天台分析

[English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md)

天台分析（英文名 **Rooftop Quant**，日文名 **屋上クオンツ**）是一个可自行部署的股票技术分析工作台，覆盖美股、港股、中国 A 股和日本股票市场。它把多周期行情、几十项技术指标和形态识别整理成一份结构化的证据清单，然后用三种可切换的方式得出结论：本地规则打分、大语言模型独立判断，或由专门的决策模型 Jev 做判断。每一次分析的结论都会被记录下来，之后自动对照实际走势，所以哪种方式更靠谱不用猜，看战绩就行。

本工具仅基于公开行情、常规技术指标及 AI 提供分析参考，不构成投资建议或买卖指导。市场有风险，投资决策请独立判断并自行承担风险。

## 最近更新（2026 年 9 月）

- **新增第三种分析模式「Jev 决策」。** 由 [Jev](https://docs.typesafe.ai)（TypeSafe 的 System One 决策模型）对证据做选择题并给出校准概率，大模型只负责依据这些结论撰写研报。评分区改为显示看多 / 震荡 / 看空三段概率条、当前阶段和多空分歧程度。
- **新增「验证记录」面板。** 每次分析自动记账，按 5、10、20 个交易日对照实际走势，统计四条轨道（纯规则、规则 + LLM、纯 LLM、Jev）的方向命中率、看多看空后的平均涨跌、评分分档表现、买入计划的止盈止损先到情况，以及 Jev 概率是否校准。
- **AI 只看事实，不看规则的多空标签。** 纯 LLM 与 Jev 两个模式发给模型的证据中去掉了规则引擎贴的偏多 / 偏空标签，只保留状态、描述和数值，由模型自己解读。
- **左右侧状态改为一道题。** 两个 AI 模式都不再分别回答左侧和右侧状态，而是判定一个阶段（左侧酝酿、右侧可执行、已涨过头……），每个阶段对应一组自洽的左右状态，不会再出现「右侧确认、左侧观察」这类矛盾。看空时也不再给出可执行买入。
- **模式重命名。** 三种模式现在叫「规则评分 + LLM」「纯 LLM 分析」「Jev 决策」。
- 经典形态的名称与描述统一为英文数据，K 线图上的标注按界面语言显示。

## 分析流程

不论选哪种模式，前半段是一样的，也不花任何 AI 费用：

1. 抓取日线和周线行情，在支持的市场合并实时快照。
2. 本地计算全部指标：均线、布林带、一目均衡表、MACD、KDJ、RSI、ATR、成交量、OBV、CMF、VPVR、支撑压力、斐波那契、18 种经典形态、24 种 K 线组合、神奇九转、艾略特波浪、缠论。
3. 把结果整理成一份**证据快照**：每条证据带状态、描述、距今几根 K 线、当前 K 线是否收盘；另附一组候选支撑位和压力位。

后半段由所选模式决定谁来下结论。三种模式共享同一份证据快照，各自独立缓存，切换模式不会复用另一种模式的结论。

### 规则评分 + LLM（默认）

本地引擎按五个维度打 0–5 分，分别评估左侧反转和右侧确认两条路径，并从候选位里算出止损与目标。配置大模型后，AI 复核这份结论，但只能在 ±0.5 分内调整，且每条理由必须引用已有证据。

这个模式的长处是稳定、可解释、可横向比较，并且没有 Key 也能用（走本地研报引擎）。它的判断由人写的公式决定，公式里的权重没有经过回测。

### 纯 LLM 分析

大模型只拿到证据快照和近期 K 线，不拿到规则分、评分上限或预设的趋势结论，也不拿到规则贴的多空标签。它在一次请求中独立给出走势、0–5 分、置信度、阶段、持仓 / 入场 / 止损建议和完整研报。

服务端负责纪律：止损和目标只能从候选位里选；没有完整止损—目标组合、或判了看空的可执行买入会被降级为等待；右侧确认时左侧不能仍在观察。这些校正只改状态，不改 AI 给出的评分。

### Jev 决策

Jev 不生成文字，只回答三种题：选择题（各选项概率）、是非题（为真的概率）、打分题（档位与置信度）。它比大模型快几十倍、便宜几百倍，输出格式固定，不会编造。代价是它不会算数、不解释理由、对英文以外的语言准确率较低。

这个模式围绕这些特点设计，分三步调用，每一步都能看到上一步的结论：

1. **逐项判读。** 对每一条证据回答「这条信号对未来 5–20 个交易日意味着偏多、中性还是偏空」。发给它的材料只有事实：状态、英文描述、距今几根 K 线；价位与现价的距离由代码提前算成「极近 / 近 / 中等 / 远」，原始指标数值不发。
2. **方向与阶段。** 判定看多 / 震荡 / 看空的概率，以及当前处于九个阶段中的哪一个。
3. **评分与计划。** 0–5 分入场评分、持仓动作、止损触发方式，并从候选支撑位和压力位里各挑一个作为止损和目标。

代码负责 Jev 不擅长的部分：从逐项判读里按概率加权统计多空分歧；校验所选止损与目标的盈亏比，低于 1.2 的可执行方案降级为观察；看空时不保留可执行买入。大模型最后只做一件事：把这些不可更改的结论解释清楚。技术研报末尾会附上 Jev 的逐项判读清单。

这个模式需要同时配置 Jev API Key 和一个大模型。Jev 目前只支持 TypeSafe 官方接口。

### 三种模式对比

| | 规则评分 + LLM | 纯 LLM 分析 | Jev 决策 |
| --- | --- | --- | --- |
| 谁下结论 | 本地规则，AI 微调 ±0.5 | 大模型 | Jev |
| 谁写研报 | 大模型（可选） | 大模型 | 大模型 |
| 需要的 Key | 无（可选大模型） | 大模型 | Jev + 大模型 |
| 置信度来源 | — | 模型自报 | 校准概率 |
| 同一输入结果是否稳定 | 是 | 否 | 基本是 |
| 典型耗时 | 秒级 | 数十秒 | Jev 约 1.5 秒 + 写报告 |

三种模式都还没有被验证过哪个更准。这正是下一节要解决的问题。

## 验证记录

右上角的剪贴板图标打开验证面板。它把每次分析的结论记下来，过一段时间再对答案。

**记账是自动的。** 每次分析完成，当前模式的结论会记一条：方向、概率、评分、阶段、左右侧状态、止损止盈、所用模型。不论你用哪个模式，都会顺带免费记一条「纯规则评分」作为基准，因为规则结果每次分析本来就会算。同一只股票、同一模式、同一交易日只保留一条。模拟数据不记。

**对答案不花钱。** 打开面板时会拉取最新行情，按 5、10、20 个交易日对照实际走势，全程不调用任何模型。满 20 个交易日的记录即定稿。

**能看到的统计：**

- 方向命中率：判看多要求涨幅超过 1.5 倍 ATR，判看空要求跌幅超过 1.5 倍 ATR，判震荡要求涨跌都在这个幅度内。
- 看多后 / 看空后的平均涨跌，对照「全部平均」。看多后的涨幅要明显高于全部平均，判断才算有用。
- 评分 ≥3.5 与评分 <2.5 的平均涨跌，看评分有没有区分度。
- 买入计划：止盈先到还是止损先到。
- Jev 概率校准：它说「看多 70%」的那批记录，事后是否约七成上涨。

记录带各模式的逻辑版本号，判断逻辑更新后新旧战绩不会混算。样本少于 30 条时数字只能参考。记录保存在当前浏览器，支持导出 / 导入 JSON，换设备或清理浏览器数据前请先导出。

## 主要功能

- 搜索四个市场的股票，在浏览器中保存分析历史和行情快照。
- 联动的价格与指标图层，日线 / 周线切换，红涨或绿涨配色，形态标注按界面语言显示。
- 左右侧情景以**未形成、观察、盘中暂定、确认、过晚**五种状态展示。
- 研报分为行情概览、策略建议、技术细节三部分；Jev 模式另附逐项判读。
- 大模型失败且已开启兜底时，规则模式自动使用内置本地研报引擎；两个 AI 模式失败时明确报错，不会暗中退回规则评分。
- 实时行情不可用时明确标记离线模拟数据，模拟数据不会发给任何模型。
- 界面支持简体中文、繁体中文、英文、日文。

## 快速开始

### 环境要求

- Node.js 20.9 或更高版本
- npm

### 安装与运行

```bash
git clone https://github.com/gunzero5158/zenith-quant.git
cd zenith-quant
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。生产环境：`npm run build && npm run start`。

## 配置

### 大语言模型

在应用右上角打开**大模型配置**，填写服务提供商（Google Gemini、OpenAI、Anthropic 或任意 OpenAI 兼容服务）、模型名称、API Key、可选的 Base URL，以及是否启用本地研报兜底。

### Jev 决策模型

同一个设置弹窗下方有 Jev 区域，填写 TypeSafe 官方 API Key；API 地址和模型名可留空，默认走 `https://api.typesafe.ai` 与 `jev-latest`。只有「Jev 决策」模式会用到它，且该模式还需要上方的大模型配置。

所有凭据保存在浏览器本地。执行分析时，凭据经由本应用的服务端接口转发至所选上游，服务端不持久化保存。默认禁止访问私有或内网地址，自部署环境连接内网模型时可显式开启：

```env
ZENITH_ALLOW_PRIVATE_LLM_HOSTS=true
```

### 可选行情源

创建 `.env.local` 可启用额外的兜底行情源：

```env
TWELVE_DATA_API_KEY=your_key
FMP_API_KEY=your_key
```

## 隐私与限制

- 分析历史、缓存研报、验证记录、显示偏好和模型设置都保存在浏览器存储或 Cookie 中；本部署没有数据库。
- 行情和模型输出来自外部服务，可能延迟、缺失、不可用或出错。
- 出现演示模式提示时，当前结果使用的是模拟数据。
- Jev 给出的概率是它对证据解读的把握，不是股价上涨的胜率；它在股票判断上的准确度尚未经独立验证，请配合验证记录使用。
- 技术指标、形态、评分和生成式研报只是概率性的决策辅助，不是价格预测或交易指令。
