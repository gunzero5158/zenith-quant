# 屋上クオンツ Rooftop Quant

[English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md)

屋上クオンツは、米国株、香港株、中国 A 株、日本株に対応するセルフホスト型のテクニカル分析ワークスペースです。マルチタイムフレームの市場データ、決定論的な指標計算、インタラクティブチャート、AI による独立した相場判断を一つの画面にまとめます。

AI 分析は公開市場データと一般的なテクニカル指標に基づく参考情報であり、投資助言や売買指示ではありません。投資判断はご自身の責任で行ってください。

## AI ネイティブな意思決定

この実験ブランチでは、ローカルのルールスコアを先に計算して AI に見直させる方式を使用しません。

1. ローカルエンジンは日足・週足を正規化し、客観的な指標値、イベント時点、データ品質、候補価格レベルだけを作成します。
2. AI が相場見通し、0-5 のエントリー魅力度、確信度、セットアップ状態、保有・エントリー・撤退方針を独立して決定します。固定ウェイト、ローカル上限、`+/-0.5` の調整制限はありません。
3. サーバーは AI の結論を置き換えず、整合性だけを検証します。参照する根拠は実在し、戦略は選択したセットアップと一致し、実行可能なエントリーには提示済みレベルから選んだ損切りと目標が必要です。
4. リスクリワードと損切り距離は、AI が選んだ価格からサーバーが計算し、算術上の矛盾を防ぎます。

確信度は結論への確からしさであり、強気度やスコアの高さではありません。データの完全性、独立した根拠の一致、時間軸間の対立、未確定足、確認・無効化までの距離を考慮し、その理由も表示します。

## 分析範囲

- トレンドと変動性: EMA、ボリンジャーバンド、一目均衡表、ATR、日足・週足の文脈。
- モメンタム: MACD、KDJ、RSI、直近クロス、閾値イベント、ダイバージェンス。
- 出来高と資金フロー: 相対出来高、OBV、CMF、価格と出来高の確認。
- 価格位置: 水平サポート/レジスタンス、フィボナッチ、VPVR、動的レベル、パターン由来レベル。
- 構造: クラシカルパターン、位置を考慮したローソク足、TD Sequential、エリオット波動のヒューリスティック、Chanlun の文脈。
- 判断結果: 強気/中立/弱気、AI スコアと確信度、左右セットアップ、4 種類の戦略、損切り、目標、算出済みリスクリワード。

AI は計算済みの値とイベント時点を受け取りますが、指標の再計算、ニュースやファンダメンタルズ、未提示価格、外部事実の追加は禁止されます。シミュレーション足を実データとして AI に分析させることもありません。

## 対応市場とデータ

| 市場 | 例 |
| --- | --- |
| 米国株 | `AAPL`、`MSFT` |
| 香港株 | `0700.HK`、`9988.HK` |
| 中国 A 株 | `600519.SS`、`000001.SZ` |
| 日本株 | `7203.T`、`9984.T` |

データの可用性は銘柄、市場、ネットワーク、上流サービスに依存します。Yahoo Finance、EastMoney、Tonghuashun、Kabutan、Tencent、任意の Twelve Data/FMP を市場に応じてフォールバックします。分析履歴の鮮度は各市場の取引時間に基づいて判断し、モックデータをライブ結果として扱いません。

## クイックスタート

Node.js 20.9 以降と npm が必要です。

```bash
git clone https://github.com/gunzero5158/zenith-quant.git
cd zenith-quant
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開き、分析前に **AI 設定** でプロバイダー、モデル、API Key を設定してください。Google Gemini、OpenAI、Anthropic、OpenAI 互換エンドポイントに対応します。

追加の市場データプロバイダーは `.env.local` で有効化できます。

```env
TWELVE_DATA_API_KEY=your_key
FMP_API_KEY=your_key
```

プライベートな AI ホストは既定で拒否されます。セルフホスト環境では `ZENITH_ALLOW_PRIVATE_LLM_HOSTS=true` で明示的に許可できます。

## プライバシーと制限

- 分析履歴、キャッシュ済みレポート、表示設定、AI 設定はブラウザストレージまたは Cookie に保存されます。
- AI 認証情報は本アプリのサーバールートを経由して選択したプロバイダーへ転送され、サーバーには意図的に永続保存されません。
- 市場データと AI 出力は遅延、不足、停止、誤りを含む場合があります。
- 指標、パターン、スコア、生成レポートは意思決定支援であり、価格予測や売買命令ではありません。
