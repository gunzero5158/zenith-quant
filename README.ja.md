# 屋上クオンツ

[English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md)

屋上クオンツ（英語名 **Rooftop Quant**、中国語名 **天台分析**）は、米国株・香港株・中国 A 株・日本株を対象に自分で運用できる株式テクニカル分析ワークベンチです。複数時間軸の株価、数十のテクニカル指標、パターン検出を 1 つの構造化された根拠スナップショットにまとめ、切り替え可能な 3 つの方法で結論を出します。ローカルのルール採点、大規模言語モデルによる独自判断、そして専用の決定モデル Jev による判断です。すべての結論は記録され、後日実際の値動きと自動で照合されるため、どの方法が信頼できるかは推測ではなく成績で判断できます。

本ツールは公開株価、一般的なテクニカル指標、AI の出力に基づく分析参考情報を提供するものであり、投資助言や売買指示ではありません。市場にはリスクがあります。投資判断はご自身で行い、結果はご自身の責任となります。

## 最近の更新（2026 年 9 月）

- **第 3 の分析モード「Jev 判定」を追加。** [Jev](https://docs.typesafe.ai)（TypeSafe の System One 決定モデル）が根拠に対する選択式の質問に較正済み確率で回答し、LLM はその結論に基づいてレポートを書くだけです。スコア欄は強気 / 中立 / 弱気の確率バー、現在の段階、根拠の強弱の対立度を表示します。
- **「検証記録」パネルを追加。** 分析のたびに自動で記録し、5・10・20 営業日後の実際の値動きと照合します。4 つのトラック（ルールのみ、ルール + LLM、LLM判断、Jev）について、方向的中率、強気・弱気判定後の平均騰落、スコア帯別の成績、エントリー計画の利確先着・損切り先着、Jev の確率が較正されているかを集計します。
- **AI に渡すのは事実のみ。** 2 つの AI モードでは、ルールエンジンが各根拠に付けた強気 / 弱気タグを渡さず、状態・説明・数値だけを渡してモデル自身に解釈させます。
- **左右の状態を 1 つの判断に。** 両 AI モードは左側と右側の状態を別々に答えるのではなく、1 つの段階（左側形成中、右側実行可、過熱…）を判定し、各段階が整合した左右の組み合わせに対応します。「右側確認なのに左側は監視中」といった矛盾は起きません。弱気判定時に実行可能なエントリーも出しません。
- **モード名を変更。** 「ルール + LLM」「LLM判断」「Jev 判定」になりました。
- チャートパターンの名称と説明を英語データに統一し、チャート上のマーカーは UI 言語で表示します。

## 分析の流れ

どのモードでも前半は共通で、AI 費用はかかりません。

1. 日足・週足を取得し、対応市場ではリアルタイム株価を統合します。
2. すべての指標をローカルで計算します。EMA、ボリンジャーバンド、一目均衡表、MACD、KDJ、RSI、ATR、出来高、OBV、CMF、VPVR、支持・抵抗、フィボナッチ、18 種のチャートパターン、24 種のローソク足パターン、TD シーケンシャル、エリオット波動、纏論。
3. 結果を **根拠スナップショット** にまとめます。各根拠には状態、説明、シグナルからの経過本数、足の確定有無が付き、候補となる支持・抵抗水準も添えられます。

後半は選んだモードが誰に結論を出させるかを決めます。3 モードは同じスナップショットを共有し、キャッシュは別々です。モードを切り替えても他モードの結論は再利用されません。

### ルール + LLM（既定）

ローカルエンジンが 5 つの軸で 0-5 点を採点し、左側の反転と右側の確認の 2 経路を別々に評価し、候補水準から損切りと目標を算出します。LLM を設定すると結論を再評価しますが、調整は ±0.5 以内に限られ、すべての理由は既存の根拠を引用しなければなりません。

安定・説明可能・銘柄間で比較可能で、キーなしでも動作します（内蔵のローカルレポートエンジン）。判断は人が書いた式によるもので、その重みはバックテストされていません。

### LLM判断

モデルが受け取るのは根拠スナップショットと直近のローソク足のみです。ルールスコア、スコア上限、事前の相場判定、ルールの強弱タグは渡しません。1 回のリクエストで見通し、0-5 点、確信度、段階、保有 / エントリー / 損切りの助言、レポート全文を独自に返します。

サーバーが規律を担います。損切りと目標は候補水準からのみ選べる、損切り・目標の組み合わせが不完全な場合や弱気判定下の実行可能エントリーは待機へ降格、右側が確認済みなら左側は監視中のままにできない。これらの補正は状態のみを変え、モデルのスコアは変えません。

### Jev 判定

Jev は文章を生成せず、3 種類の質問にだけ答えます。選択（各選択肢の確率）、はい / いいえ（真である確率）、スコア（段階と確信度）です。LLM より数十倍速く数百倍安価で、出力の形が固定されており、捏造がありません。その代わり計算ができず、理由を説明せず、英語以外では精度が下がります。

このモードはその特性に合わせ、前段の結論を見られる 3 回の依存呼び出しで構成されています。

1. **指標別の判定。** 各根拠について「このシグナルは今後 5-20 営業日にとって強気・中立・弱気のどれを意味するか」を答えます。渡す材料は事実のみです。状態、英語の説明、経過本数。各水準と現在値の距離はコードが事前に「極近 / 近 / 中 / 遠」に分類し、生の指標値は送りません。
2. **見通しと段階。** 強気 / 中立 / 弱気の確率と、9 つの段階のどれに当たるかを判定します。
3. **スコアと計画。** 0-5 のエントリースコア、保有行動、損切りトリガー、候補水準から選ぶ損切り 1 つと目標 1 つ。

Jev が苦手な部分はコードが担います。指標別判定から確率で重み付けして強弱の対立度を測る、選ばれた損切りと目標のリスクリワードを検証して 1.2 未満の実行案を監視へ降格する、弱気判定下では実行可能エントリーを残さない。LLM の仕事は 1 つ、変更不可の結論を説明することです。テクニカルレポートの末尾には Jev の指標別判定一覧が付きます。

このモードには Jev の API キーと LLM の両方が必要です。Jev は現在 TypeSafe 公式エンドポイントのみ対応です。

### 3 モードの比較

| | ルール + LLM | LLM判断 | Jev 判定 |
| --- | --- | --- | --- |
| 結論を出す主体 | ローカルルール、AI が ±0.5 調整 | LLM | Jev |
| レポート執筆 | LLM（任意） | LLM | LLM |
| 必要なキー | なし（LLM は任意） | LLM | Jev + LLM |
| 確信度の出所 | — | 自己申告 | 較正済み確率 |
| 同じ入力で同じ結果 | はい | いいえ | ほぼはい |
| 所要時間の目安 | 数秒 | 数十秒 | Jev 約 1.5 秒 + レポート |

3 モードのうちどれが正確かはまだ検証されていません。次節はそのためのものです。

## 検証記録

右上のクリップボードアイコンで検証パネルが開きます。各分析の結論を書き留め、後日答え合わせをします。

**記録は自動です。** 分析が完了すると、実行したモードの結論が記録されます。見通し、確率、スコア、段階、左右の状態、損切り、目標、使用モデル。どのモードを使っても、基準として「ルールのみ」の記録が無料で追加されます（エンジンは毎回計算しているためです）。同一銘柄・同一モード・同一営業日につき 1 件です。シミュレーションデータは記録しません。

**答え合わせは無料です。** パネルを開くと最新のローソク足を取得し、5・10・20 営業日後の値動きと照合します。モデルは呼び出しません。20 営業日を経た記録は確定します。

**表示される集計：**

- 方向的中率：強気は ATR の 1.5 倍超の上昇、弱気は 1.5 倍超の下落、中立はその範囲内の値動きが条件。
- 強気判定後・弱気判定後の平均騰落と「全体平均」の比較。強気後の上昇が全体平均を明確に上回って初めて判定が有用と言えます。
- スコア ≥3.5 と <2.5 の平均騰落。スコアに識別力があるか。
- エントリー計画：利確と損切りのどちらが先に到達したか。
- Jev の較正：「強気 70%」とした記録のうち、実際に約 7 割が上昇したか。

記録にはトラックごとの判断ロジックのバージョンが付き、ロジック更新後の成績と混ざりません。サンプルが 30 件未満のときは参考程度です。記録はブラウザに保存され、JSON のエクスポート / インポートに対応します。端末変更やブラウザデータ消去の前にエクスポートしてください。

## 主な機能

- 4 市場の銘柄を検索し、分析履歴と株価スナップショットをブラウザに保存。
- 連動する価格・指標ペイン、日足 / 週足の切り替え、赤高・緑高の配色、UI 言語で表示されるパターンマーカー。
- 左右のシナリオを **未形成、監視、日中暫定、確認、手遅れ** の 5 状態で表示。
- レポートは相場概観、戦略、テクニカル詳細の 3 部構成。Jev モードでは指標別判定を追記。
- ローカルフォールバックを有効にすると、ルールモードは LLM 失敗時に内蔵レポートエンジンを使用。2 つの AI モードは明示的にエラーを返し、暗黙にルール採点へ戻りません。
- リアルタイム株価が取得できない場合はシミュレーションデータであることを明示し、モデルには送信しません。
- UI は簡体字中国語、繁体字中国語、英語、日本語に対応。

## 設定

### 大規模言語モデル

右上の **モデル設定** を開き、プロバイダー（Google Gemini、OpenAI、Anthropic、または任意の OpenAI 互換サービス）、モデル名、API キー、任意のベース URL、ローカルレポートフォールバックの有効化を入力します。

### Jev 決定モデル

同じダイアログの下部に Jev 欄があり、TypeSafe 公式の API キーを入力します。URL とモデル名は空欄でよく、既定は `https://api.typesafe.ai` と `jev-latest` です。「Jev 判定」モードのみが使用し、このモードには上の LLM 設定も必要です。

すべての認証情報はブラウザに保存されます。分析時には本アプリのサーバールートを経由して選択した上流へ渡され、サーバー側には保存されません。プライベート / 内部ホストは既定でブロックされます。内部モデルに接続する自己ホスト環境では明示的に許可できます。

```env
ZENITH_ALLOW_PRIVATE_LLM_HOSTS=true
```

### 任意のデータプロバイダー

`.env.local` を作成すると追加のフォールバックプロバイダーを有効化できます。

```env
TWELVE_DATA_API_KEY=your_key
FMP_API_KEY=your_key
```

## プライバシーと制限

- 分析履歴、キャッシュされたレポート、検証記録、表示設定、モデル設定はブラウザストレージまたは Cookie に保存されます。このデプロイにはデータベースがありません。
- 株価とモデル出力は外部サービス由来で、遅延・欠落・利用不可・誤りの可能性があります。
- デモモードの表示がある場合、現在の結果はシミュレーションデータに基づきます。
- Jev の確率は根拠の解釈に対する確信度であり、株価が上がる勝率ではありません。株式判断での精度は独立に検証されていないため、検証記録と併せてご利用ください。
- 指標、パターン、スコア、生成レポートは確率的な意思決定補助であり、価格予測や売買指示ではありません。
